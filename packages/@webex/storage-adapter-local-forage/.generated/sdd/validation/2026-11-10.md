### I-02 — Install command source does not contain the command

- **Severity:** Important (B11-cmd)
- **Recheck:** Still present. The manifest now points `commands.install.source_file` to `../../../package.json`, which is the workspace package manifest, but that file declares the Yarn package manager rather than the `yarn install` command.
- **Evidence:** `packages/@webex/storage-adapter-local-forage/.sdd/manifest.json`; `package.json` at the monorepo root.
- **Impact:** The install command is valid, but its recorded `source_file` does not substantiate the command under the manifest-backed command check.
- **Action:** Record install-command provenance in a source file that contains the command or adjust the manifest representation so the command can be verified.
